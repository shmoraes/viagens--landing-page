Projeto desenvolvido como prática de HTML5 e CSS3, com foco em estrutura semântica e responsividade.

---

## Sobre o Projeto

O **TripMe** é uma landing page de uma agência de viagens fictícia que apresenta:

- Banner com imagem de fundo
- Navegação com âncoras internas
- Seções informativas
- Botão "Voltar ao topo"
- Layout responsivo para dispositivos móveis

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Scroll Suave (CSS)

---

## Funcionalidades

✔ Menu de navegação com links internos  
✔ Banner com imagem de fundo e overlay  
✔ Layout organizado e semântico  
✔ Design responsivo  
✔ Efeito hover nos links  
✔ Estrutura limpa e organizada  

---

## 📱 Responsividade

O projeto se adapta a diferentes tamanhos de tela utilizando:

- `flexbox`
- `@media (max-width: 768px)`
- Ajustes de tipografia e espaçamento

---

## 🚀 Como Executar

1. Baixe os arquivos
2. Certifique-se de que a imagem `banner.jpg` está na mesma pasta do `index.html`
3. Abra o arquivo `index.html` no navegador
